# ウナギの迷宮

**Current version: v2.0-alpha1**

## 概要

ウナギを操作して迷路を進み、ゴールを目指すブラウザゲームです。

ゲームシステムの基盤は完成し、現在はウナギらしい自然な動きと描画表現の向上、さらに機能追加を見据えた設計改善を進めています。

## 現在の状況

* `class Game` を中心とした複数ファイル構成へリファクタリング済み
* Ver.1.0.1 と同等のゲームプレイを維持
* 一定距離追従アルゴリズムによるウナギのニョロニョロ動作を実装
* `renderer.js` を描画メソッドごとに整理
* ベジェ曲線による涙滴形の尾先を実装
* 尾先パラメータを `config.js` に集約
* 胸びれ・目・尾端を含むプレイヤーキャラクターのデザインを完成
* スマートフォン表示で胴体描画を最適化
* ゴール演出（CLEAR表示・タイム表示・リトライ）を実装
* 壁タイルにハイライト／シャドウを追加し、人工的な水中迷宮らしい表現へ改善
* 背景に縦グラデーションを導入し、水中空間の自然な雰囲気を追加
* 複数固定ステージ対応の基盤（stages / setStage()）を実装

現在は、迷宮探索モードから派生した新ゲームモード「逃げ切りモード」の試作を進めています。

## 世界観
『ウナギの迷宮』は、人工的に作られた水中迷宮を舞台としています。

石やタイルで構成された静かな水路をウナギが泳ぎ回り、出口を探して脱出する――そんな探索的な体験を目指しています。

## 開発目標

* ウナギらしい自然な泳ぎ・シルエットの実現
* 人工水中迷宮としての統一感あるビジュアル
* ステージごとに異なる遊びを提供する構成
* PC・スマートフォンの両方で快適に遊べるゲームを目指す
